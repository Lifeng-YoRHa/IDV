# 心跳追逐 · 趣味间歇跑（IDV）

灵感来自《第五人格》的心跳机制：一个虚拟监管者在雷达上不断逼近你，
距离越近心跳声越急、红光越明显；进入"恐惧半径"后触发追击，
你必须加速冲刺拉开距离才能逃脱——天然形成高强度间歇跑（HIIT）的节奏。

纯网页应用（PWA），无需安装，iPhone Safari 打开后"添加到主屏幕"即可像 App 一样使用。

## 玩法

- **游荡**：监管者在远处游荡并逐渐逼近，心跳由慢到快
- **追击**：进入恐惧半径后触发追击警报，监管者以固定速度追你
- **逃脱**：拉开足够距离并保持 3 秒，进入恢复期
- **受击**：被追上扣一颗心，监管者暂时撤退；**两次受击则倒地，本局结束**
- **存活**：坚持到倒计时结束即为存活，结算成绩

## 难度

| 难度 | 追击速度 | 恐惧半径 | 逃脱距离 | 恢复节奏 |
|------|---------|---------|---------|---------|
| 休闲 | 3.0 m/s | 45 m | 55 m | 慢 |
| 标准 | 3.7 m/s | 40 m | 65 m | 中 |
| 梦魇 | 4.4 m/s | 35 m | 75 m | 快 |

## 本地运行

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 部署（GitHub Pages）

仓库 Settings → Pages → Source 选主分支根目录，保存后访问
`https://<用户名>.github.io/IDV/` 即可。GPS 定位需要 HTTPS，必须用部署后的网址在手机上跑。

## 使用提示

- iPhone：Safari 打开网址 → 分享 → 添加到主屏幕
- 首次开始会请求定位权限，请允许；建议开启声音（心跳为程序合成音效）
- 跑步时屏幕保持常亮，不要锁屏
- 室内可用"演示模式"体验玩法（拖动滑块模拟奔跑速度）
